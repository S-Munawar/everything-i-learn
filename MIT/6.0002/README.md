## Course Overview
This course teaches students how to use computation to solve real-world problems and accomplish a variety of goals. It focuses on building models, writing Python programs, and applying statistical and algorithmic thinking to problems such as robot vacuum simulation, virus population dynamics, and drug treatment modeling.

## Prerequisites

- **6.00.1x or equivalent** - prior programming experience in Python and a rudimentary knowledge of computational complexity

## What You'll Learn

- Advanced programming in Python 3
- Knapsack problem, graphs, and graph optimization
- Dynamic programming
- Plotting with the `pylab` package
- Random walks
- Probability and distributions
- Stochastic programming and statistical thinking
- Monte Carlo simulations
- Curve fitting
- Statistical fallacies
