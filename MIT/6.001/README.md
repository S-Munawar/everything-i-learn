# Introduction to Computer Science and Programming (MIT 6.001)
**Course:** MIT 6.001 – Structure and Interpretation of Computer Programs
**Institution:** Massachusetts Institute of Technology
**Level:** Undergraduate
**Course Link:** [https://ocw.mit.edu/courses/6-001-structure-and-interpretation-of-computer-programs-spring-2005/](https://ocw.mit.edu/courses/6-001-structure-and-interpretation-of-computer-programs-spring-2005/)

## Overview
This course introduces students to the fundamental concepts of computer science through programming. It focuses on building a strong foundation in computational thinking, algorithm design, and software engineering principles. The course emphasizes understanding how to structure and organize programs effectively.

## Topics Covered

- Programming fundamentals
- Data structures and algorithms
- Computational problem solving
- Recursion and higher-order functions
- Abstraction and modular design
- Object-oriented programming
- Functional programming concepts
- Complexity analysis
- Search and sorting algorithms
- Dynamic programming
- Graph algorithms
- Optimization techniques
- Software engineering best practices

## Learning Outcomes
By completing this course, I learned how to:

- Design and implement algorithms to solve computational problems
- Analyze and optimize code for efficiency
- Use appropriate data structures for different problem domains
- Apply object-oriented and functional programming paradigms
- Decompose complex problems into manageable components
- Test and debug programs systematically
- Understand computational complexity and trade-offs
