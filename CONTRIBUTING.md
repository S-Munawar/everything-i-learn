# Contributing to Everything I Learn

Thank you for your interest in contributing! This repository is a collection of learning materials, notes, code examples, and solutions. Contributions help make this resource more valuable for the community.

## How to Contribute

### Adding New Content

1. **Identify the Right Category**: Place your content in the appropriate folder:
   - `DSA/` - Data Structures and Algorithms
   - `Python/` - Python learning materials and exercises
   - `JavaScript/` - JavaScript learning materials
   - `MIT/` - MIT OpenCourseWare materials

2. **Follow the Naming Convention**:
   - Use descriptive, clear names for files and folders
   - Use underscores or hyphens for spaces in filenames
   - Include topic numbers when organizing sequential content (e.g., `1.topic_name.py`)

3. **Code Quality**:
   - Add comments to explain complex logic
   - Include docstrings in Python functions
   - Write clean, readable code following PEP 8 (Python) or standard conventions
   - Test your code before submitting

4. **Documentation**:
   - Include a brief description of what each file contains
   - Add comments to complex algorithms or concepts
   - Link to external resources or references when relevant
   - Create `Notes.md` or `README.md` files in folders with multiple related files

### Organization Guidelines

- **Hierarchical Structure**: Keep related materials organized in folders
- **Consistency**: Follow existing naming patterns and folder structures
- **Completeness**: If adding exercises, include solutions or hints when possible
- **Clarity**: Ensure file purposes are clear from names and internal comments

### Adding Solutions or Notes

- Include source attribution (course name, textbook, online resource)
- Add comments explaining key concepts
- For algorithms, include time and space complexity notes
- For practice problems, include the problem statement or link

### Commit Guidelines

- Use clear, descriptive commit messages
- Reference the topic or file you're modifying
- Example: "Add binary search implementation to DSA/JavaScript"

## Reporting Issues

Found an error, typo, or outdated content?
- Open an issue describing the problem
- Suggest corrections or improvements
- Include the file path and specific location

## Code of Conduct

- Be respectful and constructive
- Focus on learning and helping others learn
- Provide helpful feedback and corrections
- No plagiarism - always credit original sources

## Questions?

If you have questions about:
- Where to place new content, check the existing folder structure
- Formatting or style, follow patterns used in existing files
- Specific topics, open a discussion or issue

Happy learning and contributing! 🚀
